Advanced Features

In addition to the required project functionality, the World Countries system includes the following advanced features.

1. Interactive World Map

The system includes an interactive world map implemented with Leaflet and OpenStreetMap.

The latitude and longitude of every country are imported on the server side from the countries.dev API and stored in SQL Server. These coordinates are used to display the countries on the map.

  • Countries are displayed using interactive map markers.
  • Users can search for a country by its name or capital city.
  • The map can be filtered by geographic region.
  • Each marker displays the country's flag, name, capital, region and population.
  • Clicking a marker provides a link to the complete country details page.
Data flow: countries.dev → ASP.NET server → SQL Server → Countries API → Leaflet map

2. Live Shares Updates

The sharing page supports automatic updates using client-side polling.

While live updates are enabled, the client sends a request to the ASP.NET server every ten seconds. New content can therefore appear without requiring the user to refresh the browser page.

  • Shared content is refreshed automatically every ten seconds.
  • Shares can be filtered according to a selected country.
  • Users can search inside the shared text.
  • Users may update or delete only content that they created.
  • Each share displays its author, country and publication date.
  • Administrators can delete inappropriate shared content.
Live update flow: JavaScript timer → GET request → ASP.NET Controller → SQL Server → updated shares displayed on the page

Polling jQuery REST API SQL Server

3. AI Country Advisor

The system contains an artificial-intelligence module that combines country information stored in SQL Server with an AI language model.

A registered user selects a country and submits a question. The user can request a travel plan, cultural overview, geographic explanation or other country-related information.

  • The user selects a country stored in the project database.
  • The ASP.NET server validates the user and loads the selected country's information from SQL Server.
  • The server creates a prompt containing the country name, capital, region, languages, currencies, population and area.
  • The prompt and the user's question are sent from the server to the AI service.
  • The generated answer is returned through the ASP.NET API and displayed on the client page.
  • The OpenAI API key is stored only on the server and is never exposed in the HTML or JavaScript files.
AI request flow: AIAdvisor.html → AIController → Country model → DBservices → SQL Server → AIService → OpenAI API → generated answer

Artificial Intelligence OpenAI API ASP.NET SQL Server

Important: AI-generated information may contain mistakes. Users should verify current visa requirements, safety information, prices, opening hours, transportation details and other time-sensitive information before travelling.

Technical Summary

The advanced features are integrated with the project's existing three-layer architecture.

  • The client pages are implemented with HTML, CSS, JavaScript, jQuery and AJAX.
  • ASP.NET Controllers receive HTTP requests from the client.
  • Model classes contain the system's business functionality.
  • The DAL communicates with MS SQL Server through stored procedures.
  • External services are accessed only from the server side.
  • The client never receives database credentials or secret API keys.
