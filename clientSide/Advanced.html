Advanced Features

In addition to the required basic functionality, the following features were added to the system.

1. Interactive Map

A world map built with the Leaflet library and open OpenStreetMap tiles. Every country is placed using the Lat / Lng coordinates that are saved in the database when the countries are imported from the API on the server side.

  • Markers are coloured by the personal lists of the logged-in user: green for "Visited", blue for "Want to visit".
  • The map can be filtered by region.
  • Clicking a marker opens the flag, capital, population and a link to the country page.

2. Timed Quizzes

Two quizzes are built dynamically from the country data in the database: Guess the Capital and Guess the Flag. The questions and the wrong answers are chosen randomly on the server, so every game is different.

Security: the time limit is checked on the server and not only by the timer in the browser, so a player cannot pass the limit by changing the page. Results are saved and shown in a high score table.

3. Real Time Updates (Polling)

The shares page asks the server for new content every 10 seconds using polling, so shares written by other users appear without refreshing the page. A message tells the user how many new shares arrived, and live updates can be switched off.

The administration statistics use the same technique and refresh every 15 seconds.

4. Artificial Intelligence Module

A language model is used to enrich the content of the site:

  • An automatic travel summary for each country on the details page.
  • Destination recommendations based on the continents and languages the user saved in the preferences.

5. Technical Highlights

  • Password security: passwords are stored only as a hash. The verification is done on the server in C# and never inside an SQL query.
  • Three layer architecture: a clear separation between the Controllers, the model logic and the DAL. Every database access goes through stored procedures with parameters, which protects against SQL injection.
  • Data binding: the countries list and the users table use DataTables, with a switch between a card view and a table view.
  • One AJAX layer: all the calls to the server go through a single ajaxCall function, and all the addresses are defined once in common.js.
