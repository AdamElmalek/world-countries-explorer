Advanced Features

In addition to the required basic functionality, the following advanced features were added to the World Countries system.

1. Interactive World Map

The system includes an interactive world map created with the Leaflet library and OpenStreetMap.

Every country is displayed according to the latitude and longitude saved in the database during the countries import.

  • Countries are displayed using interactive map markers.
  • Countries can be searched by country name or capital city.
  • The map can be filtered by region.
  • Clicking a marker displays the flag, capital, region, population and a link to the full country page.

2. Timed Country Quizzes

Registered users can complete timed quizzes about countries, capitals, currencies, regions and country codes.

  • Quiz information and questions are loaded from the database.
  • Every quiz has a time limit.
  • Answers are checked by the server.
  • The score and number of correct answers are saved after completion.
  • Users can view their previous attempts and total quiz points.

3. Live Shares Updates

The shares page supports automatic live updates using polling.

When live updates are enabled, the client requests updated information from the server every 10 seconds. New shares can therefore appear without manually refreshing the page.

  • Shares can be filtered by country.
  • Users can search inside the share content.
  • A user may edit or delete only their own shares.
  • Shares display the user, country and publication date.

4. Personal Country Lists

Every registered user can create personal lists of countries.

  • Countries can be added to a Visited list.
  • Countries can be added to a Want to visit list.
  • A country can be moved from one list to the other.
  • Saved countries can be removed from the lists.
  • Every saved item contains the date on which it was added.

5. Countries API and Database Import

Country information is collected on the server side from the countries.dev API.

The imported information is converted into the system's country model and stored in SQL Server.

  • Country names, codes, capitals and regions.
  • Population, area and coordinates.
  • Flags and demonyms.
  • Multiple languages for each country.
  • Multiple currencies for each country.

6. Technical Highlights

  • Password security: passwords are stored as hashes and are never saved as plain text in the database.
  • Three-layer architecture: the Controllers, Models and DAL have separate responsibilities.
  • Stored procedures: database operations are performed using SQL Server stored procedures with parameters.
  • REST API: the client communicates with the ASP.NET server using GET, POST, PUT and DELETE requests.
  • AJAX: client requests are sent through the shared ajaxCall function.
  • Local storage: the logged-in user's information is retained between client pages.
  • Dynamic rendering: countries, personal lists, shares, quizzes and map markers are generated from server responses.
